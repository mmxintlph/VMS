Using This in Production

This Netlify version is a UI prototype — data is in-memory only. For production, connect one of these backends:

Option A — Self-hosted Python server
Use attendance-webhook/app.py from this project. Runs on your intranet. Data never leaves your premises.
Option B — Swap the API calls
Replace the API.* functions in this file to call your own REST endpoints. The full UI stays intact.
Option C — Netlify Functions
Add a netlify/functions/ folder with serverless handlers and a cloud database (Supabase, PlanetScale, etc.).
